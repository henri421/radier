# Radier

Radier rectangulaire sur ressorts de Winkler (EN 1997-3:2025, 5.2.4.2, 5.5.6, annexe B.14) : tassements,
pression du sol, zone décollée et moments de calcul de Wood-Armer. Outil de la suite
[WebAedificium](https://henri421.github.io/WebAedificium/).

Développement : `npm ci`, `npm test`, `npm run typecheck`, `npm run build` (site dans `docs/`).
